# B站课程按主题分组合并为章节笔记

B站课程视频会将完整课程切成几十个小片段（10~70个SRT），文件名仅含讲次编号不含主题。
直接逐节生成笔记会导致笔记碎片化且效率低。

## 最优策略：按主题分组 → 合并SRT → 按章生成笔记

### 步骤

**1. 采样SRT内容确定主题**

文件名通常只有编号（P2, P3...），无章节信息。读取每个SRT的开头2-3句（跳过时间轴和序号）推断讲次主题：

```python
import re

def get_topic_header(path):
    with open(path, 'r', encoding='utf-8', errors='replace') as f:
        lines = f.readlines()
    content = []
    for l in lines:
        s = l.strip()
        if not s or re.match(r'^\d+$', s) or re.match(r'^\d{2}:\d{2}:\d{2}', s):
            continue
        if 'B站up主' in s:
            continue
        content.append(s)
        if len(content) >= 3:
            break
    return content[:2]
```

**2. 按主题分组**

根据采样结果划分章节。典型电磁场/电磁波课程的分组参考：

| 章节 | 讲次 | 主题 |
|------|------|------|
| 第1章 矢量分析与场论 | P1-P3 | 梯度/散度/旋度 |
| 第2章 静电场 | P4-P11 | 电位/高斯定理/边界问题 |
| 第3章 静电能量与恒定电场 | P12-P15 | 能量/力/恒定电场 |
| 第4章 恒定磁场 | P16-P25 | 磁感应/安培定律/电感 |
| 第5章 时变电磁场 | P26-P29 | 电磁感应/麦克斯韦方程组 |
| 第6章 准静态场 | P30-P33 | 电准静态/磁准静态 |
| 第7章 平面电磁波 | P34-P40 | 波动方程/反射折射 |
| 第8章 导行电磁波 | P41-P48 | 传输线/波导 |

**3. 合并SRT并按章拆分**

将同章讲次的SRT合并为单文件，去掉时间轴和序号，保留纯文本。按20KB分组（适配代理/API限制）。

**4. 按章生成笔记**

每章作为一个任务，用API逐组调用生成。推荐用脚本（`scripts/generate_gaoshu.py` 模板）实现自动拆分+API调用+合并。

## 已知坑

- **文件名不包含章节号**：必须读SRT内容推断主题，不能依赖文件名
- **缺讲/缺集**：B站课程常有缺失，需在分组时标注
- **讲义PPT内容**：如有PDF讲义，用pdftotext提取可作为高质量上下文
- **第一讲（绪论）**：通常无P编号，单独处理
